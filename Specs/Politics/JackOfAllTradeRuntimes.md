## What is considered Jack of All Trades?

the Jack-of-all-trades flags are given to the programming context if

- Requires the runtime machine. Be it the Java / JRE, Python, NPM, or even a whole web browser like Electron & Tauri (unsure).
- Programming codes only works to said runtime machine, either interpreted, semi-compiled, or compiled, only by that machine.
- Runtime machines are available to all OSes, so Programming codes can be inserted to all OSes kind of machine. This is particularly the big reason why programmers chose to build with Java, Python, or HTML5. Your code can be brought anywhere as long as the machine is available on that OS!
- OSes are responsible & tasked exclusively to scaffold nooks and crannies of the runtime machine itself, not the programming codes, because they are usually not compiled by them at all.
