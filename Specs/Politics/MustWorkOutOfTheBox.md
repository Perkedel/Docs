# Must Work Out of the Box

A rating program evaluating certain doohickey products, whether such tech works out of the box.

The results are simple. These are,

- Works out of the box. It just works. Downloaded, unboxed, installed, and turn it on, plug and play. No extra config required
  - Feedback available for
    - Cheated. Made work by whatever it is so that it just works. E.g., using AI help. and has AI Gen bot included in Contributor list.
- Outdated. It was considered working out of the box before, but this update is broken.
- Enshitified. Same as outdated, but this time it's because it's intentional by the company making it.
- Broken. 
  - It requires extra configuration just to get it work
  - There is no binary build compatible on common architecture. You must must compile one yourself!
  - The binary is paid, despite gratis open source code
