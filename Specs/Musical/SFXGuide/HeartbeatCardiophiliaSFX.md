# Heartbeat SFX Design Guide

## Rough

- Based on Prog 126, MSB 4.
- Place this new Cardiophilia on 
  - GM2 / LS: Prog 126, MSB 99
- For variants there are
  - Only Systole
  - Only Diastole
  - Specials & Pre-made
    - Premature Ventricular Contraction
  - Alternative Control
    - Note Velocity Up down Based
      - Press is Systole
      - Release is Diastole
      - Velocity both press & release affects speed
      - Note selection defines possible different heart mushes
    - Repeating
      - Hold to play heart beating
      - Release to stop it
      - Note Selection still adjust rates
- Base is on C3 / Middle C
- Systole to Diastole adjustable with Note selection
- **Prevent pitch shifting as the note goes**, only let the sample speed change!
  - You can use e.g. Paul Stretch & Squish technology
- One press as usual is 1 Heartbeat
