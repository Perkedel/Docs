# Lung-Pulmo SFX Guide

## Rough

- This is person breathing emulator
- Variants are
  - Normal. Typical Breathing as usual
  - Noisy. Intentionally make it noisy cartoonishly
- Larynx design affects the voice noise
  - Gender
  - Larynx Size
  - Larynx Thickness
  - Larynx Mass
  - Acoustic Chamber Volume & Shape
- No longer be confusable as Breath Noise
- Hold a note to breath in
  - Velocity equals breath in velocity
- Release to breath out
  - Release velocity equals blow velocity
- Note selection adjusts breathing speeds
  - This is alternative breathing speed control
- **Prevent pitch shifting!** Only let the breathing speed sample change!
