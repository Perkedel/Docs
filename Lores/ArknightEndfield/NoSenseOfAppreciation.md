Fight as usual! Remember to dodge when you saw Red ✴️ Ding, & Parry with Skill when Orange Circle Shrink.

### Finisher

You have inflicted a DMG when this boss HP is 1 (`Finish Him` perma-daze), Type your new password (will type on `New`) & Submit!  
The window also has Key hints underneath the fields  
Just type with below keys. Confirm with `Submit` (it'll automatically fill `Confirm` field). Available keys:

- Attack. Square / Left Click
- Skill. `L1` / Top row `1`
- Dodge. Circle / Right Click
- Jump. `X` / `Space`
- Backspace. Triangle / `Backspace`
- Submit. Option / `Enter`

Submit without typing anything to select random Finisher.  
Incorrect password will skip Finisher immediately

No timer for this story event
