# Radioactive Type????

We know we got

- Cryo
- Nature
- Fire
- Electric
- Physical

But now there's a 6th element we gotta acknowledge: **Radioactive**.

Radioactive typically boosts all previous elements. Much like Wind in ZZZ, Radioactive provides power if administered in combo on those elements contact, while its linger is active. Wind's Linger, Tornado; and Radioactive's Linger, Radiation. This one, will have gas-like non-intrusive ultra-transparent bright green fog. When Allies inside this fog, their elemental Arts will be boosted while this Radiation air is active.  
As usual, allies will not receive self DMG from Radiation, unless explicitly works like that (Yixuan, Manato, Billy Starlight, all other HP based manna, etc.). Only the enemies, of course.
